> Three tier-A newsletters with public tip-forms or contact email. Submit T+3 to T+5 (after Show HN settles; you want a stable star count to cite). Each reaches 100K–500K developers daily.

## Notes

- **Don't submit before Show HN** — newsletters love using the "trending on HN" hook, but only if it's recent. Submit T+3 when the post is still warm and you have an actual star count.
- **If accepted:** these run with 1–7 day editorial lead times. Don't expect same-day publication.
- **Track placements:** each newsletter inclusion typically drives 500–2000 GitHub visits in a day, ~5–10% star conversion. Worth measuring.
- **Don't re-submit the same week if no acknowledgement.** Wait 30 days.
- **If TLDR AI rejects** (they're picky about non-VC-backed tools sometimes): the AI Engineer Weekly submission carries the same audience minus 90%; still worth doing.
- **Don't pay for sponsored placement.** It dilutes the organic signal and most of these have honest reviewers anyway.
